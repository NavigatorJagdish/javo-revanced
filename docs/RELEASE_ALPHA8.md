# Javo ReVanced 0.1.0-alpha.8

- Manager's **Save with Javo** screen saves a compatible video as MP4 or audio as M4A. It can combine compatible separate video and audio tracks on your phone. Share a video from Javo Video or paste a link in Manager. Android 10+ saves directly to Downloads; Android 8–9 uses the system file picker.
- In a fresh Javo Video patch with **Downloads** selected, Manager is the default saver for the upstream download controls. Follow the installation guide to enable the control. For playback stalls, use the supported **Spoof video streams** patch and the troubleshooting steps in the guide. Cellular quality can be set to 480p to reduce buffering on slower connections.
- Manager uses a non-debug build with a narrower Android permission set, a built-in APKMirror browser, and a pinned default patch bundle. Google Play Protect's verdict for this build is separate from these checks.
- Core uses the same previously verified binary. Keep an existing working Core installation.

See the [setup guide](https://github.com/NavigatorJagdish/javo-revanced/blob/main/docs/INSTALLATION.md) for supported formats, updates and recovery. Download the APKs or complete project ZIP from **Assets**. Compare the APKs with `SHA256SUMS`. The ZIP includes Android fixture results and security reports.
